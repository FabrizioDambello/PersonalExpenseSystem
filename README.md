# PersonalExpenseSystem
Sviluppato in C++ e PostgreSQL 
Interprete utilizzato: Visualstudio code; L'esecuzione del programma non richiede compilatore in quanto Visual studio Code esegue lo script come interprete.

Librerie aggiuntive richieste:

libpq-fe.h per gestione DB tramite interprete visual studio con c++
iostream per gli inserimenti degli input e output da console.

Istruzioni di avvio del programma:

Assicurarsi di avere visual studio code installato nel sistema.
Assicurarsi di avere PostgreSQL in esecuzione.
Creare il database presente nella cartella sql
Configurare correttamente i parametri di connessione al database nel file c++.
